Host-site Keycloak handoff

Pastes a JWT into window.Tariq.setToken(jwt). The widget forwards it to /api/chat/embed/messages; the server verifies it against EMBED_KEYCLOAK_ISSUER / EMBED_KEYCLOAK_AUDIENCE and uses kc_<sub> as the Dify user. Production hosts should use setTokenProvider instead — see the snippet below. 

<script>
  // Recommended host-site integration with keycloak-js:
  window.Tariq.setTokenProvider(async () => {
    await keycloak.updateToken(30); // refresh if <30s left
    return keycloak.token;
  });
  window.Tariq.on("authRequired", () => keycloak.login());
</script>
